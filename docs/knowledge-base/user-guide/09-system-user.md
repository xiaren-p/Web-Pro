# 用户管理

「系统 → 用户管理」维护系统用户账号、分配部门与岗位、管理级别、重置密码与头像。后端端点前缀 `/api/v1/users`。

## 权限体系

三轴模型决定用户权限：

- **admin_level（管理级别）**：`1`公司管理员 > `2`部门管理员 > `3`普通成员。数字越小权限越高。决定数据可见范围。
- **position（岗位）**：承载菜单 / 按钮权限，决定能看到哪些菜单与按钮。
- **is_superuser**：Django 超管，拥有全部权限。

## 页面入口

侧边栏：系统 → 用户管理（路由 `/system/user`）。

## 页面组成

- **左侧部门树**：按部门层级展示，点击按部门（含子部门）筛选。
- **右侧用户表格**：分页展示用户列表。
- **新增 / 编辑抽屉**：`UserFormDrawer`。

## 表格列

用户名、昵称、性别（字典 gender）、部门、岗位、管理级别、手机号、邮箱、状态（正常 / 禁用）、创建时间、操作列（重置密码 / 编辑 / 删除）。

## 搜索

关键字（用户名 / 昵称 / 手机号）、状态（正常 / 禁用）、创建时间范围。

## 新增 / 编辑表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| username | 是 | 编辑时只读 |
| password | 新增时必填 | 至少 6 位，仅新增显示 |
| nickname | 是 | 昵称 |
| deptId | 是 | 所属部门（树选择） |
| gender | 否 | 0 保密 / 1 男 / 2 女 |
| positionId | 否 | 岗位；admin 账号禁用 |
| adminLevel | 是 | 1 公司管理员 / 2 部门管理员 / 3 普通成员；默认 3 |
| mobile | 否 | 11 位手机号 |
| email | 是 | 邮箱 |
| status | 否 | 正常 / 禁用，默认正常 |

权限封顶：非超管无法创建 / 设置高于自身级别的用户。

## 操作

- **新增**：填写表单 → 确定。校验用户名 / 邮箱唯一。触发 NC 同步。
- **编辑**：回填修改。admin 账号岗位不可改。已发布不可改。触发 NC 同步。
- **重置密码**：行内「重置密码」→ 弹框输入新密码（≥6 位）。
- **删除**：勾选或行内删除（阻止删除当前登录用户）。部门管理员仅可删本部门用户。删除前先入队 NC disable。

## 个人中心

- `GET /users/profile`：个人资料详情。
- `PUT /users/profile`：更新昵称 / 手机 / 头像 / 部门 / 性别 / 邮箱。
- `PUT /users/password`：修改密码（校验原密码）。
- `POST /users/avatar`：上传头像（JPEG/PNG/WEBP，≤5MB，Magic Number 校验 + 压缩至 512×512 + 旧文件清理 + NC 同步）。

## 手机 / 邮箱绑定

- `POST /users/mobile/code`：发送手机验证码（仅校验参数，短信渠道待接入）。
- `PUT /users/mobile`：绑定手机号。
- `POST /users/email/code`：发送邮箱验证码。
- `PUT /users/email`：绑定邮箱。

## NC 同步

用户增删改均触发 `NcSyncService`（Nextcloud 同步），失败不阻断主流程仅记录 WARNING。
