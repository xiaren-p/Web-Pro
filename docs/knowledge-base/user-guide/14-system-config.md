# 参数配置

「系统 → 参数配置」集中管理系统的可配置参数，支持加密存储敏感值。后端端点前缀 `/api/v1/configs`。

## 页面入口

侧边栏：系统 → 参数配置（路由 `/system/config`）。

## 表格列

配置名称、配置键、配置值（PASSWORD 类型显示 `******`）、描述、操作列（编辑 / 删除）。

## 搜索

配置键 / 配置名称（模糊）。

## 新增 / 编辑表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| configName | 是 | 配置名称 |
| configKey | 是 | 配置键 |
| configType | 否 | 文本 / 密码，默认文本 |
| configValue | 是 | 配置值；密码类型用密码输入框；编辑时显示 `******` 表示未修改 |
| remark | 否 | 描述 |

## 加密存储

- `PASSWORD` 类型使用 Fernet 对称加密（AES-128-CBC + HMAC-SHA256），密钥来自 `FERNET_SECRET_KEY`。
- 读取时返回掩码 `******`，不暴露密文 / 明文。
- 编辑时提交 `******` 表示未修改密码，后端跳过更新。
- `FERNET_SECRET_KEY` 必须在 `.env` 中配置，否则 PASSWORD 类型无法加解密。

## 刷新缓存

点击「刷新缓存」调用 `POST /configs/refresh-cache`。**当前为占位实现**，直接返回成功，无实际缓存刷新逻辑。

## 注意事项

- 修改配置后如未生效，需检查是否有缓存机制（当前刷新缓存为占位）。
- 前端编辑按钮权限码 `sys:config:update` 与后端映射的 `sys:config:edit` 可能不一致，需核对菜单 perms 数据。
