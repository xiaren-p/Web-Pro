# 部门管理

「系统 → 部门管理」维护组织架构，部门以树形结构展示，用户归属于部门。后端端点前缀 `/api/v1/depts`。

## 页面入口

侧边栏：系统 → 部门管理（路由 `/system/dept`）。

## 表格列（树表）

部门名称、部门编号、状态（正常 / 禁用）、排序、操作列（新增子部门 / 编辑 / 删除）。

## 搜索

部门名称、状态。

## 新增 / 编辑表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| parentId | 是 | 上级部门（树选择），顶层选「顶级部门」 |
| name | 是 | 部门名称 |
| code | 是 | 部门编号 |
| sort | 是 | 显示排序，min 0，默认 1 |
| status | 否 | 正常 / 禁用，默认正常 |

## 操作

- **新增**：工具栏「新增」或行内「新增」（指定父级）→ 填写 → 确定。触发 NC 同步。
- **编辑**：行内编辑 → 回填 → 修改 → 确定。循环引用校验（禁止上级为自身 / 子孙）。触发 NC 同步。
- **删除**：勾选或行内删除 → 二次确认（HTML 警告框提示 NC 群组立即删除、成员失去文件夹权限、文件夹保留为孤立状态，建议先备份）→ 确认。先入队 NC 群组删除再删记录。

## 数据权限

部分业务模块的数据可见范围受部门约束，由后端 `dept_scope.py` 计算当前用户可见的部门集合。部门管理员仅可操作本部门及子孙部门。

## 下拉接口

- `GET /depts/tree`：全量树。
- `GET /depts/options`：启用部门下拉；部门管理员仅自身及子部门。
