# 字典管理

「系统 → 字典管理」维护全局数据字典，供各业务模块下拉选项与枚举翻译使用。后端端点前缀 `/api/v1/dicts`。

## 页面入口

侧边栏：系统 → 字典管理（路由 `/system/dict`）。

## 两层结构

- **字典类型**（`DictType`）：一类字典（如 `gender` 性别、`notice_type` 通知类型）。
- **字典项**（`DictItem`）：某类字典下的具体取值（如 `1 → 男`）。

## 字典类型

### 表格列

字典名称、字典编码、状态（启用 / 禁用）、操作列（字典数据 / 编辑 / 删除）。

- 「字典数据」按钮：跳转到字典项页（携带 dictCode / title / status），字典禁用时按钮禁用。

### 搜索

字典名称 / 编码（模糊）。

### 表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| name | 是 | 字典名称 |
| dictCode | 是 | 字典编码，unique |
| status | 否 | 启用 / 禁用，默认启用 |

## 字典项

### 表格列

字典项标签、字典项值、排序、状态、操作列（编辑 / 删除）。字典禁用时顶部警告且新增 / 编辑 / 删除禁用。

### 搜索

标签 / 值（模糊）。

### 表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| label | 是 | 显示文本 |
| value | 是 | 实际值，同字典下唯一 |
| status | 否 | 启用 / 禁用，默认启用 |
| sort | 否 | 排序，默认 1 |
| tagType | 否 | 标签样式：primary / success / info / warning / danger；空则纯文本；带预览 |

## 实时同步

字典变更通过 STOMP WebSocket 实时推送到所有在线客户端，无需刷新即可生效（`useDictSync` composable）。

## 内置兜底

`gender` 字典缺失时内置兜底：男(1) / 女(2) / 保密(0)。

## 选项接口

`GET /dicts/<dict_code>/items/options`：仅启用项，供业务模块下拉使用。
