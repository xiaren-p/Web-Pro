# AI 助手

AI 助手是系统内置的智能对话助手，基于 Dify 大语言模型，支持流式对话、思考模式、Plan Mode 结构化方案、会话与分组管理、全文搜索、导出与快捷键。入口为页面右侧的 AI 助手抽屉（通常通过顶部或侧边栏的 AI 按钮打开）。

## 打开与关闭

- 点击界面中的 AI 助手入口按钮，右侧滑出 1080px 宽的抽屉。
- 按 `Esc` 关闭抽屉。
- 抽屉的开关状态与当前会话会被记忆，刷新或重新进入后自动恢复。

## 新建对话

- 点击左上角「新建对话」按钮，或按 `Ctrl/Cmd + /` 新建。
- 在底部输入框输入问题，回车发送（`Shift + Enter` 换行）。
- 首条提问的前 30 字会自动作为会话标题。

## 思考模式

输入区附近有「思考」开关（chip）：

- **开启思考**：使用 R1 深度推理模型，回答前会先展示以 `Impl` 标记的折叠「深度思考」过程，再给出正式答案。适合复杂分析、策略推演。
- **关闭思考**：使用 V3 秒级快答模型，直接给出答案。适合简单提问、快速查询。

思考过程块可折叠展开，不占用正式答案区域。

## Plan Mode（结构化方案卡片）

当 AI 判断需要用户做选择时，会输出一个 **Plan 方案卡片** 代替纯文本：

- 卡片包含标题、描述、可选项。
- **单选 / 多选**：根据方案类型，选项前显示单选圆点或复选框。
- **自定义输入**：若方案允许，会出现「其他」输入框让你补充自定义内容。
- **确认 / 取消**：点击确认按钮执行方案；若方案可取消，则显示取消按钮。
- 确认执行后会有审计留痕，便于追溯。

Plan 卡片完全由后端返回的标准 Schema 驱动渲染，确保前后端一致。

## 流式回复与取消

- 回复是**流式逐字生成**的，边生成边显示。
- 生成中可点击「取消」按钮中断生成（会调用取消接口并停止 Celery 任务）。
- 即使关闭浏览器或刷新页面，后端 Celery 任务仍会继续生成；重新打开后可从历史回放看到完整内容，进度不丢。

## 会话管理

左侧栏列出历史会话：

- **置顶**：会话右上角下拉菜单可置顶 / 取消置顶，置顶会话排在最前。
- **重命名**：下拉菜单选择重命名。
- **删除**：下拉菜单选择删除（会级联删除该会话所有消息）。
- **导出 Markdown**：下拉菜单选择导出，会下载 `<标题>_<日期>.md` 文件，Plan 内容导出为 JSON 代码块。
- **移到分组**：下拉菜单可将会话移入自定义分组。

会话列表默认按「置顶优先 + 最近更新」排序，最多展示前 100 条。

## 分组管理

可自定义分组来归类会话（例如「采购」「广告优化」）：

- 新建分组、重命名、删除分组。
- 拖拽调整分组顺序。
- 将会话移入或移出分组；删除分组后，其中的会话自动归为「未分组」。

## 全文搜索

- 点击左侧栏搜索框，或按 `Ctrl/Cmd + K` 聚焦搜索。
- 输入关键词，会同时匹配会话标题与消息内容，并高亮显示匹配片段（snippet）。
- 标题匹配优先于内容匹配。

## 快捷键

仅在 AI 抽屉打开时生效，编辑输入时不抢键：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/Cmd + K` | 聚焦搜索框 |
| `Ctrl/Cmd + /` | 新建对话 |
| `Esc` | 关闭抽屉 |

## 常见问题

- **回答中断 / 失败**：会显示失败提示，可点击「重新生成」重试。
- **看不到流式输出**：检查网络，SSE 订阅会先回放已落库内容再续接实时流。
- **敏感数据**：AI 的 `DIFY_API_KEY` 仅在后端读取，前端任何位置不会出现密钥。
