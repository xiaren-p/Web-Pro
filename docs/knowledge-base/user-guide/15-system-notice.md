# 通知公告

「系统 → 通知公告」用于发布系统内公告，支持发布、撤回、已读跟踪与导出。后端端点前缀 `/api/v1/notices`。

## 页面入口

侧边栏：系统 → 通知公告（路由 `/system/notice`）。

## 公告管理（管理员）

### 表格列

标题、通知类型（字典 notice_type）、发布人、通知等级（字典 notice_level）、目标类型（全体 / 指定）、发布状态（未发布 / 已发布 / 已撤回）、操作时间、操作列。

### 搜索

标题、发布状态（未发布 / 已发布 / 已撤回）。

### 新增表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| title | 是 | 通知标题 |
| type | 是 | 通知类型（字典 notice_type） |
| level | 否 | 通知等级：L 低 / M 中 / H 高，默认 L |
| targetType | 否 | 1 全体用户 / 2 指定用户，默认全体 |
| targetUserIds | 否 | 指定用户（多选搜索），仅 targetType=2 显示 |
| content | 是 | 通知内容（WangEditor 富文本），去 HTML 标签后非空校验 |

保存后始终为草稿状态。

### 操作

- **发布**：草稿 / 已撤回状态点「发布」→ 状态变已发布 + 写入发布时间。
- **撤回**：已发布点「撤回」→ 状态变已撤回 + 写入撤回时间。
- **编辑 / 删除**：仅未发布状态可操作。已发布不可编辑（返回 400）。
- **查看**：详情弹窗展示全部字段 + 富文本内容。
- **导出**：选择筛选条件 → 下载 xlsx。非管理员自动加 `onlyMine=true` 仅导出当前用户可见公告。导出含字典翻译、目标用户账号 / 昵称、HTML 去标签。

## 我的通知（普通用户）

`MyNotice` 组件展示当前用户收到的公告：

- 未读高亮，表格列：标题、类型、发布人、等级、发布时间、状态（已读 / 未读）。
- 点击查看 → 自动标记已读（`POST /notices/<id>/read`）。
- 「全部已读」一键标记所有已发布为已读（`POST /notices/read-all`）。

## 已读跟踪

`NoticeRead` 表记录每个用户对每条公告的已读状态（user + notice 唯一约束）。管理员可查看发布范围与已读情况。

## 数据模型

- `Notice`：标题、内容（HTML）、类型、等级、目标类型、状态（draft / published / revoked）、发布时间、撤回时间、创建人。
- `NoticeTarget`：指定目标用户（notice + user 唯一约束）。
- `NoticeRead`：已读记录（user + notice 唯一约束）。
